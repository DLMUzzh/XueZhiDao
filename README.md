# 知光社区 - 知识分享与智能问答平台

## 📝 项目概述

**知光社区**是一款面向知识创作者与学习者的现代化知识社区APP，致力于打造高效、安全、智能的知识分享与交流生态系统。平台支持知识发布、社交互动（点赞/收藏/关注）、个性化内容推荐（Feed流）、对象存储直传、AI智能摘要生成及深度问答等核心功能，同时预留付费功能扩展空间，为未来商业化奠定基础。

系统各模块均采用高并发、高可用架构设计，确保在大规模用户访问和数据增长情况下仍能保持稳定高效运行。

## ✨ 核心模块与技术亮点

### 1. 认证系统：JWT双令牌安全架构

基于Spring Security深度定制的**JWT双令牌认证系统**，实现安全与性能的完美平衡：

- **双令牌机制**：15分钟短期访问令牌(Access Token) + 7天长期刷新令牌(Refresh Token)，兼顾安全性与用户体验
- **安全加固**：采用RS256非对称加密签名，防止令牌伪造；Redis维护刷新令牌白名单，支持**即时令牌撤销**
- **会话管理**：令牌过期自动刷新，无需用户重复登录，异常情况可强制登出所有设备

### 2. 计数系统：Redis SDS二进制紧凑计数方案

针对笔记维度(点赞/收藏)与用户维度(关注/粉丝)的高频计数场景，设计高性能计数系统：

- **底层存储**：Redis作为核心存储，采用**定制化Redis SDS二进制紧凑计数**，大幅节省内存空间
- **原子操作**：使用Lua脚本封装复杂计数逻辑，保证并发场景下数据一致性
- **数据保障**：实现采样一致性校验与自愈重建机制，定期校验Redis与数据库数据，发现不一致自动修复

### 3. 发布系统：渐进式发布与OSS直传优化

构建高效稳定的内容发布流程，支持图片、视频、Markdown文档等多种格式内容：

- **对象存储**：采用阿里云OSS作为内容存储介质，提供高可用、高扩展性的存储能力
- **传输优化**：**后端预签名+前端直传**模式，绕过应用服务器直接上传至OSS，节省服务器带宽与资源
- **AI赋能**：接入DeepSeek AI实现**一键生成文章摘要**，提升内容创作效率与可读性

### 4. 用户关系系统：事件驱动的一主多从架构

实现高性能关注/取关功能，支持千万级用户关系数据处理：

- **架构设计**：采用**一主多从+事件驱动**模型，关注表为主库，粉丝表、计数系统、列表缓存作为伪从库
- **事务保障**：关注事件发生时，在同一事务中插入关注表和Outbox表，确保数据一致性
- **异步同步**：Canal订阅Outbox表binlog，将变更事件发布到Kafka，异步更新其他数据源，提升写入性能

### 5. 点赞系统：分片位图+Kafka异步写聚合

应对高并发点赞场景，设计高效可靠的点赞系统：

- **高并发处理**：**Kafka异步写+写聚合**模式，合并高频写入请求，降低数据库压力
- **幂等判重**：采用**分片位图**结构高效实现点赞操作幂等性与快速判重，空间效率极高
- **数据恢复**：读取异常或缺失时，基于位图做**按需重建**，保证最终一致性；Kafka消息提供"灾难回放"兜底能力

### 6. Feed流：三级缓存+热点防护架构

构建高性能、低延迟的个性化内容推荐系统：

- **三级缓存**：本地Caffeine缓存 + Redis页面缓存 + Redis片段缓存，多级缓存协同提升访问速度
- **热点优化**：自定义**hotkey探测机制**，基于热点检测按层级延长缓存时长，叠加随机抖动防止缓存雪崩
- **并发控制**：设置**单飞锁(single-flight)** 避免同一页面并发回源导致的数据库风暴，提升系统稳定性

### 7. AI问答系统：知光RAG智能问答平台

实现围绕单篇知文的深度智能问答，大幅提升知识获取效率：

- **全流程优化**：用户调用接口→索引检查→向量检索→Prompt构造→大模型流式生成，端到端优化
- **性能提升**：合理分块策略、幂等删除保持单一版本、预索引机制减少首次提问等待时间
- **精准回答**：基于RAG技术，结合文档上下文生成准确回答，解决大模型"幻觉"问题

### 8. 搜索系统：Elasticsearch智能检索方案

构建高效、精准的内容搜索与联想建议功能：

- **核心能力**：支持关键词检索、标签过滤，采用**search_after游标分页**保证深分页稳定性
- **排序优化**：通过function_score融合BM25相关性与点赞等业务权重，提升搜索结果质量
- **联想建议**：使用ES的completion suggester实现**低延迟前缀联想**，提升用户搜索体验

## 🎯 核心优势

1. **高并发支持**：全链路异步化、多级缓存、限流熔断等机制，轻松应对百万级用户并发访问
2. **数据一致性**：事务保障、事件驱动、数据校验与重建，确保数据最终一致性
3. **智能体验**：AI摘要生成、RAG智能问答，提升内容创作与消费效率
4. **安全可靠**：双令牌认证、权限控制、数据加密，保障用户信息与资产安全
5. **可扩展性**：微服务架构、模块化设计，支持功能扩展与水平扩容
